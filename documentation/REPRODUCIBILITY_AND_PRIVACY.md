# Publication export

Only research artifacts relevant to this project are included. Operational shell logs, process locks, bytecode, private home-directory paths, machine-environment reports, and old error logs were removed. Original input archives remain untouched outside this export. Scientific source modules, raw measurement files, training snapshots, and spectra were preserved; the export manifests identify any metadata-only redactions. The byte hashes of retained scientific files can be checked without rerunning experiments.

The existing detailed analysis results are historical artifacts generated in earlier analysis passes. The current publication-preparation pass checks their packaging and table consistency; it does not claim that all simulation or optimization work has been repeated. Earlier raw archives have new container-level hashes after curation. File-level hashes and recorded scientific protocol hashes remain the relevant provenance checks.

A public repository is intended but is not created by merely preparing these files. This package contains no access tokens, SSH credentials, or GitHub authentication material. The publication helper uses the user's normal GitHub CLI sign-in on their own machine and never requests an access token to be pasted into chat.
